# 🎯 AI-Powered Smart Attendance & Security System

An intelligent attendance and security monitoring system that uses **Face Recognition**, **Computer Vision**, and **Artificial Intelligence** to automate employee attendance tracking and detect unauthorized individuals.

## 🚀 Features

### 👤 Face Registration

* Register new employees using a webcam
* Capture multiple face samples
* Generate and store face embeddings
* Save employee information in MySQL

### 🎥 Real-Time Face Recognition

* Detect faces from live webcam feed
* Identify registered employees
* Display recognition confidence score
* Real-time attendance verification

### 📅 Smart Attendance Management

* Automatic attendance recording
* Present, Late, and Absent status tracking
* Duplicate attendance prevention
* Daily attendance logs

### 🔒 Security Monitoring

* Detect unknown individuals
* Security incident logging
* Alert management system
* Security dashboard integration

### 📊 Analytics Dashboard

* Employee directory
* Attendance history
* Attendance trends visualization
* Department performance analytics
* Interactive charts and reports

### 📄 Automated Reporting

* PDF report generation
* Attendance summaries
* KPI monitoring
* AI-generated insights

## ▶️ Usage

### Test Database

```bash
python app/main.py --mode test-db
```

### Register Employee

```bash
python app/main.py --mode register
```

### Start Attendance Recognition

```bash
python app/main.py --mode attendance
```

### Launch Dashboard

```bash
streamlit run dashboard/streamlit_app.py
```
